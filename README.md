# smart-navi.github.io
============================================================
スマホのお困りごと相談（低認知コスト・AIリダイレクトフォーム）
============================================================

■ 同梱ファイル
1. index.html
   スマホ前提の相談フォーム本体です。外部ファイルやサーバー処理は
   一切不要で、このHTMLファイル1つだけで完結して動作します。

2. README.txt
   本説明書ファイルです。

■ 仕組みの概要
- フォームで選択・入力された内容をもとに、IT不慣れな方向けの
  進行制御ルール（専門用語・カタカナ語禁止、Android表記なし、
  1ステップずつ案内、最後に1〜3の番号付き選択肢を提示）を自動で
  組み立て、ChatGPT（https://chatgpt.com/?q=...）へ渡します。
- ポップアップやモーダルは一切使用せず、画面内のインライン案内のみで
  操作を完結させる設計です。

■ 公開・設置方法（完全無料）
サーバー費用やAPI費用はかかりません。以下のような無料ホスティングに
index.html を置くだけでスマホからアクセスできるようになります。

・GitHub Pages
・Cloudflare Pages
・Netlify Drop（フォルダごとドラッグ＆ドロップで即公開可能）

公開したURLをスマホのブラウザ（Safari / Chrome）で開き、
「ホーム画面に追加」をしておくとアプリのようにワンタップで開けます。

■ 運用上の補足
- 遷移先のChatGPTはログインなしでも利用可能ですが、一定回数やり取りを
  続けるとアカウント登録やログインを促す画面が表示される場合があります。
  フォーム下部の案内文に「途中でログイン画面が出たら『ログインせずに
  続ける』を押してください」と記載してあります。
